# Module 3: Parameter Estimation and Model Evaluation

## Overview

This module explores how pharmacokinetic (PK) model parameters can be estimated from simulated concentration-time data and how the reliability of those estimates can be evaluated.

Previous modules focused on forward simulation, where known PK parameters were used to generate concentration-time profiles. This module reverses that process: simulated observations are treated as experimental data, and numerical optimisation is used to recover the underlying PK parameters.

The module progresses from one-compartment parameter estimation to residual analysis, sampling design, parameter uncertainty and Monte Carlo parameter recovery. These concepts are then extended to a two-compartment model, where parameter identifiability and sampling design become more challenging.

All experiments use simulated data, allowing estimated parameters to be compared with their known true values.

## Learning Objectives

- Understand nonlinear parameter estimation in compartmental PK models.
- Generate simulated observations with residual error.
- Understand how sampling times influence parameter estimation.
- Implement nonlinear least-squares fitting using `scipy.optimize.curve_fit`.
- Evaluate model fit using residuals, MAE and RMSE.
- Interpret parameter uncertainty using covariance matrices and standard errors.
- Understand parameter correlations and their implications for identifiability.
- Apply Monte Carlo simulation to evaluate parameter recovery across repeated datasets.
- Compare sampling designs using bias, empirical standard deviation and RMSE.
- Recognise numerical instability, optimisation failures and limitations of parameter estimation.

### 1.1 Nonlinear least-squares estimation

The fitting procedure estimates parameters by minimising the sum of squared differences between observed and predicted concentrations:

\[
SSE=\sum_{i=1}^{n}(C_{obs,i}-C_{pred,i})^2
\]

The implementation uses `scipy.optimize.curve_fit`, which returns:

- `popt`: estimated model parameters.
- `pcov`: estimated parameter covariance matrix.

The diagonal elements of the covariance matrix provide estimated parameter variances. Their square roots give the estimated standard errors:

\[
SE(\hat{\theta}_j)=\sqrt{pcov_{jj}}
\]

The off-diagonal elements describe covariance between parameter estimates.

### 1.2 Residual error simulation

Noisy observations are generated by adding random error to the model-predicted concentrations.

For proportional residual error:

\[
C_{obs,i}=C_{pred,i}+\epsilon_i
\]

\[
\epsilon_i\sim N(0,(CV\cdot C_{pred,i})^2)
\]

where CV is the coefficient of variation.

For example, a CV of 0.10 represents a residual standard deviation equal to 10% of the predicted concentration.

### 1.3 Residual analysis and model evaluation

Residuals are calculated as:

\[
Residual_i=C_{obs,i}-C_{pred,i}
\]

Two numerical metrics are used:

**Mean Absolute Error (MAE)**

\[
MAE=\frac{1}{n}\sum_{i=1}^{n}|C_{obs,i}-C_{pred,i}|
\]

**Root Mean Squared Error (RMSE)**

\[
RMSE=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(C_{obs,i}-C_{pred,i})^2}
\]

Residual plots and numerical metrics provide complementary information about model fit. A low RMSE alone does not establish that the model structure is appropriate.

### 1.4 Parameter uncertainty and correlation

The parameter correlation matrix can be calculated from the covariance matrix:

\[
Corr_{ij}=\frac{Cov_{ij}}{SE_iSE_j}
\]

Strong positive or negative correlations indicate that parameter estimates tend to vary together or in opposite directions.

This can suggest that different parameter combinations produce similar model predictions, making individual parameters difficult to estimate independently.

## 2. Experiments and Findings

### Experiment 1: One-compartment parameter estimation

**Objective:** Recover the parameters of a one-compartment IV bolus model from simulated concentration-time observations.

**Approach:**

1. Generate a concentration-time profile using known PK parameters.
2. Select sampling times.
3. Add residual error to the sampled concentrations.
4. Fit the model to the noisy observations.
5. Compare estimated parameters with their known true values.

**What I learned**

- Parameter estimation reverses the forward simulation process.
- Nonlinear optimisation can recover underlying parameters from noisy observations.
- Initial parameter estimates (`p0`) influence the optimisation process.
- Parameter bounds can restrict the optimiser to a specified parameter range.
- A visually good fit does not necessarily mean that every parameter has been estimated accurately.

**Limitations**

The simulated data follow the same structural model used for fitting. This does not evaluate how well the model performs when the assumed structural model is incorrect.

### Experiment 2: Residual error and model evaluation

**Objective:** Investigate how simulated residual variability affects observed concentrations and evaluate model fit using residuals and error metrics.

**What I learned**

- Observed concentrations deviate from model predictions once residual error is introduced.
- Under proportional error, the absolute magnitude of residual variability increases with concentration.
- Residual plots can reveal systematic patterns that are not apparent from the concentration-time profile alone.
- MAE and RMSE summarise prediction errors, but should be interpreted alongside visual diagnostics.
- The residual error model is an important assumption in parameter estimation.

**Limitations**

The simulated error structure is predefined and may not represent the full complexity of experimental or clinical PK data.

### Experiment 3: Sampling time selection

**Objective:** Investigate how selecting different sampling times influences the information available for parameter estimation.

**What I learned**

- Sampling times determine which portions of the concentration-time profile contribute to parameter estimation.
- Early observations can provide information about rapid distribution and the initial concentration decline.
- Later observations help characterise the terminal elimination phase.
- The number of observations alone does not determine estimation quality. Their timing and distribution are also important.

**Limitations**

Sampling times were selected manually rather than using formal optimal design methods. Practical clinical constraints, such as patient burden and sampling costs, were not considered.

### Experiment 4: One-compartment parameter recovery using Monte Carlo simulation

**Objective:** Evaluate the reliability of parameter estimation across repeated noisy datasets.

**Method**

Repeatedly generate noisy datasets using the same underlying one-compartment model, fit the model to each dataset and store the estimated parameters and standard errors.

**What is Monte Carlo simulation?**

Monte Carlo simulation is a computational method that uses repeated random sampling to investigate the behaviour of a system under uncertainty.

Each replicate represents a possible noisy dataset generated from the same underlying PK model. Repeating the fitting procedure allows the distribution of estimated parameters to be examined.

**Evaluation metrics**

Bias:

\[
Bias=\overline{\hat{\theta}}-\theta_{true}
\]

Empirical standard deviation:

\[
SD=\sqrt{\frac{\sum_{i=1}^{N}(\hat{\theta}_i-\overline{\hat{\theta}})^2}{N-1}}
\]

RMSE:

\[
RMSE=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(\hat{\theta}_i-\theta_{true})^2}
\]

Mean estimated standard error: the average standard error obtained from the parameter covariance matrices across successful fits.

**What I learned**

- A single successful fit cannot establish whether an estimation procedure is reliable.
- Bias measures systematic estimation error, whereas empirical SD measures variability across repeated estimates.
- RMSE combines bias and variability into one measure of estimation error.
- Comparing empirical SD with the average estimated standard error helps assess whether model-based uncertainty reflects the observed variability across simulations.
- Repeated simulations can reveal estimation problems that may not be apparent from a single dataset.

**Limitations**

Results depend on the assumed model and residual error structure. A finite number of simulations also introduces Monte Carlo variability.

### Experiment 5: Two-compartment parameter estimation

**Objective:** Extend nonlinear parameter estimation from a one-compartment model to a two-compartment IV bolus model.

The four parameters estimated were:

- Central volume of distribution (\(V_c\))
- Peripheral volume of distribution (\(V_p\))
- Intercompartmental clearance (\(Q\))
- Systemic clearance (\(CL\))

The model is described by:

\[
\frac{dA_c}{dt}
=-\frac{CL+Q}{V_c}A_c+\frac{Q}{V_p}A_p
\]

\[
\frac{dA_p}{dt}
=\frac{Q}{V_c}A_c-\frac{Q}{V_p}A_p
\]

**What I learned**

- Two-compartment models are more challenging to estimate because they contain more parameters and describe more complex concentration-time behaviour.
- Parameters can influence the concentration-time profile in interdependent ways.
- The covariance matrix provides information about parameter uncertainty and correlations.
- Strong parameter correlations can indicate that the data do not contain enough information to estimate individual parameters independently.
- Parameter uncertainty should be considered alongside estimated values.

**Example finding**

In one fitting example, the correlation between \(V_p\) and \(CL\) was approximately -0.54, suggesting a moderate negative association between their estimates in that particular fit.

**Limitations**

The covariance matrix is a local approximation based on the fitted model and residual assumptions. It does not fully capture all sources of uncertainty.

### Experiment 6: Comparing two-compartment sampling schedules

**Objective:** Investigate how different sampling schedules affect two-compartment parameter estimation.

Three sampling schedules were compared:

| Schedule | Sampling times (hours) | Design |
|---|---|---|
| A | 0.2, 0.5, 1, 2, 4, 8, 12, 24 | Balanced across the profile |
| B | 0.2, 0.5, 1, 1.5, 2, 2.5, 3, 4 | Early-phase sampling |
| C | 1, 2, 4, 6, 8, 12, 18, 24 | Later-phase sampling |

**What I learned**

- Schedule A captured information from both the early distribution phase and the later terminal phase.
- Schedule B performed poorly, particularly for \(V_p\), because it lacked later observations to characterise the terminal phase.
- Schedule C captured more terminal-phase information but did not characterise the earliest distribution behaviour as effectively as Schedule A.
- Sampling design should capture the different phases of the concentration-time profile rather than concentrate observations in only one region.

**Limitations**

The initial comparison used individual noisy datasets. A single dataset is insufficient to establish which schedule performs best overall.

### Experiment 7: Two-compartment parameter recovery and Monte Carlo sampling design comparison

**Objective:** Extend the sampling schedule comparison using repeated simulations to evaluate parameter recovery more robustly.

**Method**

For each of the three sampling schedules:

1. Generate a simulated concentration-time profile.
2. Select observations according to the sampling schedule.
3. Add random residual error.
4. Fit the two-compartment model.
5. Store parameter estimates, standard errors and covariance information.
6. Repeat across 200 simulated datasets.

This produces up to 600 fitting attempts across the three schedules.

**Monte Carlo results**

The following table summarises the results from the latest bounded fitting experiment. Parameter order is \(V_c\), \(V_p\), \(Q\), and \(CL\).

| Parameter | Schedule | Mean estimate | Bias | Empirical SE | RMSE |
|---|---|---:|---:|---:|---:|
| \(V_c\) | A | 10.105 | 0.105 | 0.789 | 0.796 |
| | B | 9.562 | -0.438 | 1.567 | 1.627 |
| | C | 10.142 | 0.142 | 1.357 | 1.365 |
| \(V_p\) | A | 21.917 | 1.917 | 5.063 | 5.413 |
| | B | 57.404 | 37.404 | 43.966 | 57.724 |
| | C | 22.809 | 2.809 | 7.593 | 8.096 |
| \(Q\) | A | 2.088 | 0.088 | 0.260 | 0.274 |
| | B | 3.282 | 1.282 | 2.350 | 2.677 |
| | C | 2.064 | 0.064 | 0.256 | 0.264 |
| \(CL\) | A | 2.991 | -0.009 | 0.172 | 0.172 |
| | B | 2.714 | -0.286 | 1.861 | 1.883 |
| | C | 2.967 | -0.033 | 0.205 | 0.208 |

**Interpretation**

- Schedule A had the lowest RMSE across all four parameters in this simulation, indicating the best overall parameter recovery.
- Schedule B showed substantially poorer parameter recovery, particularly for \(V_p\). It had the highest bias, empirical variability and RMSE for most parameters.
- Schedule C demonstrated intermediate performance. It recovered \(Q\) and \(CL\) relatively well but showed greater uncertainty in \(V_c\) and \(V_p\) than Schedule A.
- The results support the importance of collecting observations across both the early distribution and later terminal phases.

**Parameter uncertainty and fitting instability**

The average estimated standard errors were:

| Parameter | Schedule A | Schedule B | Schedule C |
|---|---:|---:|---:|
| \(V_c\) | 0.710 | 2.104 | 1.303 |
| \(V_p\) | 4.858 | 90,451,577.724 | 6.324 |
| \(Q\) | 0.249 | 45,956.840 | 0.243 |
| \(CL\) | 0.159 | 45,953.521 | 0.180 |

Schedule B produced extraordinarily large average estimated standard errors for \(V_p\), \(Q\) and \(CL\). These values are much larger than the corresponding empirical standard deviations across the simulated estimates.

This suggests that some individual fitting replicates produced extremely large covariance-based uncertainty estimates. The average estimated standard error may therefore be dominated by a small number of unstable fits.

The distinction is important:

- **Empirical SE** describes the observed variability of parameter estimates across Monte Carlo replicates.
- **Estimated SE** describes uncertainty calculated from the covariance matrix of an individual fit.

The two measures are not interchangeable.

**Numerical and estimation challenges**

Some fits produced extremely large standard errors and unstable parameter estimates. Some optimisation attempts also failed to converge, while the numerical simulator generated overflow and invalid-value warnings when extreme parameter combinations were explored.

This highlighted two related issues:

1. **Poor identifiability:** The sampling schedule may not provide enough information to distinguish certain parameter combinations.
2. **Numerical instability:** Extreme parameter values explored by the optimiser can cause numerical integration errors, particularly when using Euler's method.

Parameter bounds can restrict extreme estimates, but they do not automatically resolve poor identifiability. A successful optimisation does not guarantee that the resulting parameters are reliable.

**Limitations**

- Only three manually selected sampling schedules were compared.
- Results depend on the simulated parameter values, residual error and fitting settings.
- The finite number of replicates introduces Monte Carlo variability.
- The experiment does not account for real clinical sampling constraints.
- Euler integration may become unstable when extreme parameter combinations are explored.
- Parameter bounds can influence estimation results and should be justified rather than selected solely to obtain convergence.

## 3. Overall Takeaways

1. **Parameter estimates must be evaluated with their uncertainty.** A good visual fit does not guarantee that individual parameters are accurately estimated.
2. **Residual diagnostics complement numerical metrics.** Residual patterns can reveal systematic discrepancies that a single error metric may conceal.
3. **Sampling design affects parameter identifiability.** Observations should capture the informative portions of the concentration-time profile.
4. **Monte Carlo simulation provides a more comprehensive assessment of estimation performance.** Repeated parameter recovery reveals bias, variability and unstable fitting behaviour.
5. **Complex models require more information.** Two-compartment models can have correlated parameters that are difficult to estimate independently.
6. **Numerical stability matters.** The optimiser, parameter bounds and numerical integration method can all influence parameter estimation.
